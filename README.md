# salonidalal.com

Personal site for Saloni Dalal — a compact monospace résumé page in the spirit of quiet terminal-style CVs.

## Stack

- [Astro](https://astro.build) (static)
- [Tailwind CSS](https://tailwindcss.com)
- Self-hosted [JetBrains Mono](https://www.jetbrains.com/lp/mono/) (SIL OFL)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

Connect the repo to Vercel or Cloudflare Pages and attach `salonidalal.com`.
